explore-like-a-user: a new skill that explores a whole app as first-time users would, on phone, desktop and keyboard, and reports what is broken, confusing, visually off, inaccessible or slow, plus what could be better. It keeps the app's journeys and known findings in the repo's docs, so each run reports only what is new, worse or fixed. try-every-surface: walker.md now lets a brief name another file that overrides it, which explore-like-a-user's explorers use; try-every-surface's own runs are unchanged.
