explore-like-a-user: a new skill that explores a whole app as first-time users would, on phone, desktop and keyboard, and reports what is broken, confusing, visually off, inaccessible or slow, plus what could be better. You can type it, and the model or an automation can start it too. It keeps the app's journeys and known findings in the repo's docs, so each run reports only what is new, worse or fixed. try-every-surface: its walker instructions can now be overridden by a file the sub-agent is pointed at, which explore-like-a-user uses; try-every-surface's own runs work as before.
